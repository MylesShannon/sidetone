Sidetone 1.1.4

Signed and notarized by Apple.

  • Sidetone now carries a Developer ID signature and Apple's notarization, so a downloaded copy opens like any other app, with no stop in Privacy & Security first.
  • Because the signature changed, macOS asks for the microphone once more the first time you start monitoring. If Sidetone stops opening at login, turn on Open Sidetone at login in Settings again.
