Sidetone 1.0.0

First release.

  • Sends any input to any output, so you can hear your own microphone, or a line-in from something else.
  • Capture and playback run on independent clocks, joined by a ring buffer with drift correction, so mismatched devices keep working.
  • Level meter, spectrum, gain in dB with a click-free ramp, and a safety limiter.
  • Latency profiles that start as tight as your devices allow and back off if your Mac cannot keep up.
  • Global shortcuts, named presets, and devices remembered across unplugging.
  • Stops and starts itself around sleep, and tells you if a device disappears.
